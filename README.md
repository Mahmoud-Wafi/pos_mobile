# 📱 نظام إدارة محل الموبايلات والمحافظ الإلكترونية
## Mobile Shop POS, Inventory & E-Wallet Management System

نظام متكامل وشامل لإدارة محلات الهواتف المحمولة والإلكترونيات، تم تصميمه خصيصاً ليناسب متطلبات السوق المصري من تتبع دقيق لأرقام السيريال (IMEI)، إدارة المحافظ الإلكترونية وشبكات الدفع (فودافون كاش، إنستاباي، وغيرها)، والعمليات النقدية والآجلة، مع واجهة مكتبية سريعة باللغة العربية (RTL) تعمل **دون الحاجة لأي اتصال بالإنترنت (100% Offline)**.

## 🌟 نظرة عامة والمميزات الأساسية

صُمم النظام لتجاوز المشاكل التقليدية لبرامج الكاشير في محلات الهواتف:
- **تتبع أجهزة الهاتف برقم السيريال المزدوج (Dual-IMEI):** التحقق التلقائي من صحة السيريال (15 رقماً عبر خوارزمية Luhn) ومنع تكرار أي سيريال مسجل في النظام نهائياً.
- **إدارة احترافية للمحافظ الإلكترونية:** مصفوفة العمليات الست (إيداع، سحب، تحويل، سداد فواتير، بيع رصيد)، مع نظام عمولات متدرج، حد يومي وشهري للمحفظة، وجرد ختامي للأرصدة.
- **إقرار قانوني لشراء الأجهزة المستعملة:** توليد وثيقة قانونية رسمية فورية بصيغة PDF قابلة للطباعة تتضمن بيانات البائع، الرقم القومي، حالة الجهاز، والسيريال لحماية المحل من الأجهزة مجهولة المصدر.
- **نظام حسابات وورديات دقيق:** ربط الكاشير بوردية ودرج نقدية، جرد أعمى للنقدية عند الإغلاق (Blind Reconciliation) مع تسجيل الفائض والعجز تلقائياً.
- **واجهة مستخدم عصرية (Clean Arabic UI):** تصميم مريح وواضح بالخط العربي (Cairo)، مصمم خصيصاً للاستخدام اليومي المكثف مع ألوان متباينة وبدون أي تعقيد.

## 🛡️ المبادئ الهندسية الصارمة

يلتزم النظام بـ 8 قواعد هندسية ومالية صارمة لا تقبل المساومة:

1. **التعامل بالقروش الصحيحة (Integer Piasters Only):**
   جميع المبالغ المالية في قاعدة البيانات والعمليات الحسابية تُخزن وتُعالج كأرقام صحيحة بالقروش (`100 قرش = 1 جنيه مصري`). لا يتم استخدام أرقام عشرية (`float`) نهائياً لتفادي أخطاء التقريب المالي.
2. **العمليات الذرية (Atomic DB Transactions):**
   أي عملية شراء أو بيع أو تحويل نقدي تتم داخل معاملة واحدة شاملة (`Single Database Transaction`). في حالة فشل أي جزء، يتم التراجع عن المعاملة بالكامل (`Rollback`) لمنع أي تباين في الأرصدة أو المخزون.
3. **عدم قابلية السجلات المنشورة للتعديل (Immutability):**
   الفواتير والعمليات المالية والتحويلات بعد اعتمادها (`Posted`) غير قابلة للتعديل أو الحذف المباشر؛ التصحيح يتم فقط عبر فواتير مرتجع أو حركات تسوية قيد معتمدة.
4. **حماية الصلاحيات على مستوى الخدمات (Service Layer RBAC):**
   فحص الصلاحيات يتم داخل دوال الخدمات (`Service Layer`) برفع استثناء صريح `PermissionDenied` في حال عدم امتلاك المستخدم للصلاحية، حتى لو تم الضغط على الزر في الواجهة.
5. **سجل تدقيق كامل (Audit Logging):**
   تسجيل أوتوماتيكي لكل العمليات الحساسة (تسجيل دخول، بيع، مرتجع، خصم، سحب مالك، تسوية جرد) متضمناً معرّف المستخدم، التوقيت، ونوع العملية.
6. **فصل كامل للنصوص والتعريب (`app/i18n/ar.py`):**
   كافة المصطلحات ورسائل التنبيهات معزولة في ملف اللغة العربية الموحد لمنع أي نصوص عشوائية في الشيفرة.
7. **محرك عمولات وحدود ديناميكي:**
   قواعد العمولات والحدود اليومية/الشهرية للمحافظ تعتمد على قواعد بيانات قابلة للتحديث وليس قيماً ثابتة مشفرة في الكود.
8. **تغطية شاملة بالاختبارات المؤتمتة:**
   أكثر من 114 اختباراً آلياً بـ `pytest` يغطي كافة القواعد الحسابية والمالية والأمنية.

## 💻 التقنيات المستخدمة

- **لغة البرمجة:** Python 3.10+
- **واجهة المستخدم الرسومية:** PySide6 (Qt for Python) بنظام RTL العربي وخط Cairo.
- **قاعدة البيانات:** SQLite 3 مع تفعيل وضع الكتابة المسبقة السريعة الآمنة (`WAL - Write-Ahead Logging`) ودعم المفاتيح الأجنبية (`PRAGMA foreign_keys = ON`).
- **محرك قواعد البيانات (ORM):** SQLAlchemy 2.0.
- **إدارة ترحيل قواعد البيانات (Migrations):** Alembic.
- **توليد الفواتير والمستندات (PDF Generation):** ReportLab.
- **تشفير كلمات المرور:** Argon2 / PBKDF2 عبر `hashlib` و `secrets`.
- **أطر الاختبار:** Pytest 8.x.

## 🖥️ شرح شاشات وأقسام النظام

### 1. لوحة المؤشرات والتحكم (Dashboard)
- **بطاقات الأداء السريعة (KPIs):**
  - مبيعات اليوم (إجمالي المبيعات وعدد الفواتير).
  - صافي أرباح اليوم (تُحجب تلقائياً في حال عدم امتلاك المستخدم صلاحية استعراض الأرباح).
  - رصيد درج النقدية المباشر للكاشير.
  - إجمالي أرصدة المحافظ الإلكترونية المتاحة.
  - تنبيهات النواقص (عدد الأصناف التي بلغت أو تجاوزت حد الطلب الأدنى).
  - حالة الوردية الحالية (مفتوحة/مغلقة، اسم الكاشير، وقت الفتح).
- **أزرار الوصول السريع (Quick Shortcuts):** للوصول بنقرة واحدة إلى شاشات نقطة البيع، المحافظ، المشتريات، الخزينة، العملاء، والمخزون.
- **موجز العمليات الحية:**
  - جدول أحدث 5 فواتير مبيعات اليوم.
  - جدول الأصناف الناقصة لتنبيه المشتريات فوراً.

### 2. نقطة البيع والمبيعات (POS & Sales)
- شاشة كاشير سريعة مصممة للعمل بلوحة المفاتيح والماسح الضوئي (Barcode Scanner).
- **إدخال المنتجات:** عبر الباركود، البحث الفوري بالاسم، أو إدخال السيريال (IMEI) مباشرة للهواتف.
- **منع تكرار بيع السيريال:** التحقق اللحظي من أن الجهاز بحالة `in_stock` وقفل المعاملة لمنع بيع نفس السيريال مرتين.
- **طرق الدفع المتعددة (Split Payment):**
  - دفع نقدي (Cash).
  - دفع عبر المحفظة الإلكترونية (Vodafone Cash / InstaPay).
  - دفع ببطاقة بنكية (Card).
  - دفع آجل على حساب العميل (Credit) مع فحص الحد الائتماني للعميل.
- **طباعة الفواتير:**
  - توليد نص إيصال حراري (Thermal Receipt 80mm).
  - توليد فاتورة ضريبية وضمان PDF بتفاصيل السيريال والشروط.

### 3. إدارة المخزون وتتبع أجهزة السيريال (IMEI)
- تبويبات منفصلة:
  - **المنتجات:** عرض كميات الأصناف، أسعار الشراء والبيع، الحد الأدنى، وإضافة وتعديل المنتجات.
  - **الأجهزة (IMEI):** سجل كامل لكل جهاز هاتف (الموديل، IMEI 1، IMEI 2، الحالة الفيزيائية، تاريخ الدخول، التكلفة، والحالة الحالية).
  - **نواقص المخزون:** عرض الأصناف التي تتطلب إعادة طلب من الموردين فوراً.
  - **جرد المخزون (Stocktake):** مطابقة الكمية الفعلية مع الكمية المسجلة وحساب الفروقات وتوليد حركات تسوية مخزنية معتمدة تلقائياً.
- استيراد وتصدير بيانات المخزون من وإلى ملفات Excel.

### 4. المرتجعات وإدارة الضمان (Returns & Warranty)
- البحث الفوري عن الفاتورة برقمها أو برقم السيريال (IMEI).
- فحص سريان فترة الضمان المحددة لكل صنف.
- خيارات الإرجاع:
  - استرجاع نقدي للعميل (مع خصم المبلغ من درج الكاشير).
  - استبدال صنف بآخر مع تسوية الفارق المالي.
- إعادة الجهاز أو الصنف المرتجع تلقائياً للمخزون بحالة `in_stock`.

### 5. المشتريات والموردين (Purchases & Suppliers)
- تسجيل فواتير الشراء من الموردين بالأجل أو نقداً.
- تسجيل أجهزة الهواتف بالسيريال دفعة واحدة أو عبر ماسح الباركود.
- **حساب التكلفة المرجحة (Weighted Average Cost):** تحديث تلقائي لسعر تكلفة الصنف بناءً على الكمية والتكلفة السابقة والتكلفة الجديدة في الفاتورة.
- إدارة حسابات الموردين، كشف حساب المورد، وسداد الدفعات النقدية.

### 6. شراء الأجهزة المستعملة والإقرارات القانونية
- شاشة مخصصة لاستلام الأجهزة المستعملة من العملاء.
- تسجيل بيانات البائع (الاسم الرباعي، الرقم القومي المكون من 14 رقماً، رقم الهاتف، العنوان).
- تسجيل تفاصيل الجهاز (الموديل، السيريال، اللون، السعة، الحالة والعيوب).
- **توليد إقرار التنازل والبيع (Legal Declaration A4):** طباعة مستند رسمي فوري يقر فيه البائع بملكيته القانونية للجهاز وخلوه من أي شبهة جنائية مع مكان مخصص لتوقيع البائع وبصمته.

### 7. المحافظ الإلكترونية والعمولات (E-Wallets & Commissions)
- إدارة كاملة لخطوط وأجهزة فودافون كاش، أورنج كاش، إي آند كاش، وي باي، وإنستاباي.
- **مصفوفة العمليات الست:**
  1. `cash_in`: إيداع نقدي للعميل (خصم من رصيد المحفظة + استلام كاش في الدرج).
  2. `cash_out`: سحب نقدي للعميل (إضافة لرصيد المحفظة + دفع كاش من الدرج).
  3. `transfer_in`: تحويل مستلم على المحفظة.
  4. `transfer_out`: تحويل صادر من المحفظة.
  5. `bill_pay`: سداد فواتير وشحن رصيد.
  6. `balance_transfer`: تحويل رصيد بين خطوط ومحافظ المحل.
- **محرك العمولات المتدرج:** حساب العمولة والربح تلقائياً بناءً على شريحة المبلغ ونوع العملية.
- **مراقبة الحدود:** تنبيه ومنع العمليات في حال تجاوز الحد اليومي أو الشهري للمحفظة.
- **جرد المحافظ اليومي:** مطابقة الرصيد الدفتري المسجل مع الرصيد الفعلي على الشريحة.

### 8. المحاسبة والخزائن والورديات (Accounting & Shifts)
- **شجرة الحسابات النقدية:** إدارة حسابات متعددة (درج الكاشير Cash Drawer، الخزينة الرئيسية Safe، الحساب البنكي).
- **التحويلات النقدية:** تحويل الأموال بين الدرج والخزينة بحركات ذرية متبادلة.
- **المصروفات النثرية:** تصنيف وتسجيل المصروفات اليومية (كهرباء، بوفيه، إيجار، صيانة).
- **مسحوبات المالك (Owner Draws):** فصل مسحوبات الأرباح الشخصية للمالك عن مصروفات التشغيل لضمان صحة تقارير الأرباح والخسائر.
- **إدارة الورديات:** فتح الوردية بمبلغ عهدة أولي، وإغلاق الوردية بجرد أعمى ومقارنة النقدية المتوقعة مع الفعلية مع ترحيل الفروقات.

### 9. العملاء وحسابات الآجل (Customers & Debts)
- قاعدة بيانات العملاء المسجلين وسجلات الهواتف والعناوين.
- تتبع مديونيات العملاء والحدود الائتمانية.
- تحصيل دفعات الديون وتوليد إيصالات السداد وتحديث رصيد العميل فورياً.

### 10. التقارير التفصيلية والأرباح (Reports & P&L)
- **تقرير المبيعات التفصيلي:** تصفية بحسب التاريخ والموظف مع مجاميع الإيرادات والخصومات وصافي المبيعات.
- **قائمة الأرباح والخسائر الشاملة (P&L):**
  $$\text{صافي الربح} = \text{أرباح المبيعات} + \text{أرباح وعمولات المحافظ} - \text{المصروفات النثرية} \pm \text{فروقات عجز/زيادة الورديات}$$
- **تقرير تقييم المخزون:** حساب القيمة الإجمالية للمخزون بسعر التكلفة وسعر البيع المتوقع.
- **تقرير عمولات المحافظ:** تحليل عمليات الشحن والسحب والعمولات المكتسبة لكل خط.
- **تقرير المديونيات وحسابات الآجل:** ديون العملاء ومستحقات الموردين.
- **تقرير حركة النقدية:** كشف حساب شامل لحركة السيولة داخل وخارج كل خزينة.
- **تصدير إلى Excel:** تصدير كافة التقارير إلى ملفات CSV بترميز `UTF-8 with BOM` المتوافق مباشرة مع برنامج Microsoft Excel العربي.

### 11. الإعدادات والأمان والنسخ الاحتياطي (Settings)
- **النسخ الاحتياطي الفوري:** إنشاء نسخة احتياطية مضغوطة من قاعدة البيانات بنقرة زر واحدة.
- **استعادة النسخ الاحتياطية بأمان:** حفظ نسخة أمان من البيانات الحالية تلقائياً قبل تنفيذ أي استعادة لمنع ضياع أي بيانات.
- إدارة المستخدمين وتغيير كلمات المرور المشفرة بأعلى معايير الأمان.

## 🗄️ مخطط وهيكل قاعدة البيانات

يحتوي النظام على الجداول الرئيسية التالية في SQLite:
- `users`, `roles`, `permissions`, `role_permissions`: نظام المستخدمين والأدوار.
- `categories`, `brands`, `products`: شجرة الأصناف والمنتجات.
- `devices`, `stock`, `stock_movements`: الأجهزة برقم السيريال وحركات المخزون.
- `shifts`, `sales`, `sale_items`, `sale_payments`: الورديات، الفواتير، وبنود الدفع.
- `suppliers`, `purchases`, `purchase_items`, `supplier_payments`: الموردون وفواتير الشراء.
- `used_device_purchases`: عقود شراء الأجهزة المستعملة وبيانات بطاقة الرقم القومي.
- `wallets`, `commission_rules`, `wallet_transactions`, `wallet_audits`: المحافظ الإلكترونية والعمولات.
- `cash_accounts`, `cash_transactions`, `expenses`, `expense_categories`, `owner_draws`: الحسابات النقدية والمصروفات.
- `customers`, `customer_payments`: العملاء وحسابات الآجل.
- `audit_logs`: سجل التدقيق ومراقبة النشاط.

## 🚀 التثبيت والتشغيل السريع

### المتطلبات الأساسية
- نظام تشغيل Linux أو Windows 10/11 أو macOS.
- تثبيت بيئة **Python 3.10** أو أحدث.

### خطوات التثبيت

1. **استنساخ المستودع والدخول للمجلد:**
   ```bash
   git clone https://github.com/your-repo/POS_Mobile.git
   cd POS_Mobile
   ```

2. **إنشاء البيئة الافتراضية وتفعيلها:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate  # في نظام لينكس
   # أو في ويندوز:
   # .venv\Scripts\activate
   ```

3. **تثبيت الحزم المطلوبة:**
   ```bash
   pip install -r requirements.txt
   ```

4. **تطبيق ترحيلات قاعدة البيانات:**
   ```bash
   alembic upgrade head
   ```

5. **توليد البيانات التجريبية الأولية (حسابات، أصناف، محافظ، موردين):**
   ```bash
   python scripts/seed_demo.py
   ```

6. **تشغيل التطبيق:**
   ```bash
   python main.py
   ```

### بيانات الدخول الافتراضية (بيئة التطوير)
- **المدير (Manager):** اسم المستخدم: `admin` | كلمة المرور: `admin123`
- **الكاشير (Cashier):** اسم المستخدم: `cashier1` | كلمة المرور: `cashier123`
- **موظف المحافظ (Wallet Staff):** اسم المستخدم: `wallet1` | كلمة المرور: `wallet123`

## 📦 بناء ملف التشغيل لـ Windows

لإنشاء ملف تنفيذي مستقل (`.exe`) يعمل دون الحاجة لتثبيت بايثون:

1. تثبيت حزمة PyInstaller:
   ```bash
   pip install pyinstaller
   ```

2. تشغيل أمر البناء:
   ```bash
   pyinstaller --noconsole --name "POS_Mobile" \
     --add-data "assets:assets" \
     --add-data "alembic.ini:." \
     --add-data "migrations:migrations" \
     --icon "assets/icon.png" \
     main.py
   ```

3. ستجد الملف التنفيذي الجاهز للاستخدام داخل مجلد `dist/POS_Mobile`.
